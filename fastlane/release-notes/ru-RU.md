# Release notes (ru-RU)

Свежий раздел сверху. `scripts/release-notes.js` берёт первый раздел и пишет его в
`fastlane/metadata/android/ru-RU/changelogs/`. Держите раздел короче 500 символов.

## 2026-11-24

Первый релиз.

- Один мастер-ключ — уникальный пароль для каждого сайта: одинаковые входные данные всегда дают тот же пароль, совместимо с PawHash и Firefox Password Hasher.
- Keeper хранит метки сайтов и их настройки в зашифрованном виде (AES-256-GCM, ключ в Android Keystore).
- Мастер-ключ стирается сразу при уходе приложения в фон, буфер обмена очищается через 30 секунд.
- Новый облик: новая иконка и тёмная/светлая темы — по системе или на выбор.
- Английский, русский и немецкий языки.
